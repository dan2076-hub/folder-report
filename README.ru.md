# folder-report

Отчёт о размере файлов, расширениях и крупнейших файлах с необязательным поиском точных дубликатов. Python 3.11+, без зависимостей во время работы.

```sh
git clone https://github.com/dan2076-hub/folder-report.git
cd folder-report
python -m pip install .
folder-report ./sample-files --top 10
folder-report ./sample-files --duplicates --exclude "*.tmp" --json
```

Из исходников: `python -m folder_report` с теми же параметрами. `--top 0` скрывает список крупнейших файлов. Повторяемый `--exclude` использует `fnmatch` для имени и относительного пути, с учётом регистра; это не синтаксис `.gitignore`.

По умолчанию исключаются папки `.git`, `.venv`, `venv`, `node_modules`, `__pycache__`. Символические ссылки и Windows junction/reparse points пропускаются. Жёсткие ссылки учитываются один раз, если файловая система предоставляет надёжный идентификатор.

С `--duplicates` файлы группируются по размеру, проверяются SHA-256, затем сравниваются побайтно. Совпадение хеша само по себе недостаточно. Размер — логическая длина файлов, а не занятое место на диске. Сумма дубликатов не гарантирует столько же освобождённого физического места.

Файлы не удаляются и не изменяются. ОС может обновить время последнего доступа. Сканирование не является атомарным снимком: недоступные или изменившиеся во время чтения файлы отмечаются в `issues`. Результат с `complete=false` неполный.

Коды: `0` — отчёт готов, даже если найдены дубликаты; `1` — неполный отчёт; `2` — недопустимая корневая папка или аргументы. JSON перенаправляйте за пределы сканируемой папки.

Тесты: `python -m unittest discover -s tests -v`. Подробная JSON-схема и ограничения — в [README.md](README.md). Лицензия MIT.
